### Exemples de Qualité

#### Exemple 1 : Théorème de Lagrange (Algèbre 6)
```
Question : Montrer que |O(x)| · |Stab(x)| = |G|

Correction détaillée :
"Soit φ: G/Stab(x) → O(x) définie par φ(gStab(x)) = g·x.

Bien définie : Si g'∈gStab(x), alors g'=gh avec h∈Stab(x), 
donc g'·x = g·(h·x) = g·x.

Injective : φ(g₁Stab(x)) = φ(g₂Stab(x)) ⇒ g₁·x = g₂·x 
⇒ g₂⁻¹g₁·x = x ⇒ g₂⁻¹g₁ ∈ Stab(x) ⇒ g₁Stab(x) = g₂Stab(x).

Surjective : Par définition de O(x).

Donc |G/Stab(x)| = |O(x)|, d'où |G|/|Stab(x)| = |O(x)|."
```

#### Exemple 2 : Convergence Dominée (Analyse 6)
```
Question : Peut-on appliquer la convergence dominée à fₙ(x) = n·sin(x/n) ?

Correction :
"Oui. |fₙ(x)| = n|sin(x/n)| ≤ n·|x/n| = x (car |sin(u)| ≤ |u|). 

Donc |fₙ(x)| ≤ x pour tout n, x. 

La fonction g(x)=x est intégrable sur [0,π]. 

Par le théorème de convergence dominée, 
lim∫fₙ = ∫(lim fₙ) = ∫x dx = π²/2."
```
