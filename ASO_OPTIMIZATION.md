1. **Utiliser les mots-clés primaires** dans le titre et la description courte

3. **Varier les formulations** pour couvrir différentes recherches utilisateur
4. **Inclure des synonymes** : agrégation/agreg, mathématiques/maths, leçons/fiches
5. **Cibler les intentions** : préparation, révision, exercices, oral, écrit

## Notes pour l'implémentation

### Apple App Store
- Le nom et le sous-titre doivent être exactement conformes aux limites de caractères
- Les mots-clés doivent être séparés par des virgules sans espaces supplémentaires
- La description peut inclure des emojis pour améliorer la lisibilité
- Le texte promotionnel peut être mis à jour régulièrement pour les événements spéciaux

### Google Play Store
- Le titre doit être optimisé pour les recherches mais rester lisible
- La description courte apparaît dans les résultats de recherche - elle doit être accrocheuse
- La description longue peut inclure des sections avec emojis pour structurer le contenu
- Utiliser des sauts de ligne pour améliorer la lisibilité

### Optimisations continues
- Surveiller les performances des mots-clés dans les analytics des stores
- A/B tester différentes descriptions pour optimiser les conversions
- Mettre à jour le contenu lors de l'ajout de nouvelles fonctionnalités
- Adapter les mots-clés selon les tendances de recherche saisonnières (périodes de concours)
