## 🚀 COMMENT UTILISER L'APPLICATION

### **1. Premier Lancement**
- Créez un compte (anonyme si souhaité)
- Choisissez vos préférences (thème, notifications)
- Créez votre première sauvegarde !

### **2. Révision Quotidienne**
- Consultez votre planning du jour
- Révisez les flashcards dues
- Complétez un exercice classique
- Passez un examen blanc

### **3. Préparation d'Oral**
- Tirez deux sujets de leçons
- Préparez pendant 3h (Pomodoro)
- Simulez l'oral devant le jury virtuel
- Consultez les questions du jury

### **4. Suivi de Progression**
- Consultez vos statistiques
- Débloquez des badges
- Maintenez votre streak
- Comparez-vous aux autres

### **5. Sauvegarde Régulière**
- Créez un backup chaque semaine
- Exportez vos données
- Partagez entre appareils

## 🎯 CONSEILS D'UTILISATION

### **Pour l'Écrit**
1. Faites 1 examen blanc par semaine
2. Révisez 10 exercices classiques par jour
3. Relisez les corrections détaillées

### **Pour l'Oral**
1. Simulez 2 oraux par semaine
2. Chronométrez votre préparation (3h)
3. Préparez les questions du jury
4. Consultez les développements associés

### **Pour la Compréhension**
1. Lisez 1 concept intuitif par jour
2. Faites le lien avec les fiches
3. Résolvez l'exercice associé
4. Regardez les vidéos recommandées
